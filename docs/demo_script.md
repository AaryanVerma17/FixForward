# Three-minute demo script (target 2:45)

0:00–0:20 — Introduce FixForward: users need help deciding what to investigate next when an appliance fails.
0:20–0:45 — Enter a fan case with a repair quote and replacement price.
0:45–1:15 — Show the actual Decider typed question, options, returned choice, confidence, and latency. Make sure the UI is connected to the real endpoint.
1:15–1:40 — Show the selected tool execute and display the cost calculation or retrieved evidence.
1:40–2:05 — Show the Bedrock explanation and identify supplied facts, calculations, and uncertainty.
2:05–2:25 — Enter a burning-smell case and show deterministic safety override.
2:25–2:40 — Show the reusable decision-pattern README and test results.
2:40–2:45 — Close with the value: a reusable, observable decision step inside an agent workflow.

Never show fabricated confidence, latency, or benchmark values. If a service is in demo fallback mode, disclose it.
